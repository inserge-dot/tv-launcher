# tv-launcher — сборки

Готовые сборки домашнего лаунчера для Android TV и файлы, по которым он обновляет себя и приложения.
Исходного кода здесь нет.

- **Releases → vN** — лаунчер (`launcher.apk`), N — номер сборки. Лаунчер сам проверяет последний выпуск.
- **Releases → apps** — файлы приложений из `apps.json`.
- `apps.json` — какие версии приложений лаунчер предлагает установить или обновить.
- `lampa/repair.js` + `lampa/settings.json` — плагин для Lampa/bylampa: применяет настройки из `settings.json`,
  когда в нём увеличили `revision`.
